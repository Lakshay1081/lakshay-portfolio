# Lakshay Pareek — UI/UX Portfolio

React + Vite portfolio with responsive layouts for desktop, tablet, and mobile.

## Run locally

```bash
npm install
npm run dev
```

The About page uses `src/assets/about-character.png` and intentionally displays it without a decorative container, border, or background panel. The desktop About intro is sized against the viewport so the first section does not exceed the screen simply because of the page's global top padding.

## Resume PDF
The portfolio links directly to `public/resume/Lakshay-Pareek-UIUX-Resume.pdf`. The Resume navigation item opens the PDF in a new tab; the About page also provides view/download actions.


## Contact page
The Contact page uses the existing portfolio design system and the existing transparent character asset. It keeps direct contact links for email, LinkedIn, and GitHub, with external profiles opening in new tabs. On the Contact page only, the global closing CTA is reduced to a quieter ending.
